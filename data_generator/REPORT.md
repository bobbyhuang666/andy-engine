# Andy Engine 合成数据生成实验报告

> 生成日期: 2026-05-31
> 引擎: Rust SoA f32 (rayon 并行)
> 硬件: Apple M1, 16GB RAM

## 1. 实验概述

本次实验使用 Andy Engine 的 Rust SoA 引擎批量生成心理学驱动的多智能体社会模拟数据，用于 LLM 角色扮演微调训练。

### 1.1 场景设计

| 阶段 | 场景 | 规模 | 天数 | 种子数 | 采样间隔 |
|------|------|------|------|--------|----------|
| Phase 1 | 中等规模校园 | 5,000 agents | 30天 | 1 | 120min |
| Phase 2 | 多随机种子校园 | 2,000 agents | 15天 | 50 | 60min |
| Phase 3 | 年度长周期 | 1,000 agents | 365天 | 1 | 120min |
| Phase 4 | 极端人格对比 | 200 agents | 15天 | 10 | 20min |

### 1.2 总产出

| 指标 | 数值 |
|------|------|
| 成功场景 | 61/62 |
| 总数据点 | **44,340,000** |
| 输出大小 | 2.0 GB |
| 总耗时 | 7 分钟 |
| 数据格式 | .f32 二进制 + JSON 统计 |

## 3. 效价（Valence）分析

### 3.1 多随机种子一致性

50 个独立随机种子的最终效价：

```
均值: +0.0241
标准差: 0.0001
变异系数: 0.4%
最小: +0.0240  最大: +0.0243
```

**结论**: 效价在随机种子间高度一致（CV<1%），说明系统行为稳定，不依赖特定随机初始化。

### 3.2 年度趋势

```
D1:   +0.02145
D61:  +0.02870  (+33.8%)
D121: +0.03105  (+44.8%)
D181: +0.03230  (+50.6%)
D241: +0.03281  (+53.0%)
D301: +0.03300  (+53.8%)
D366: +0.03318  (+54.7%)
```

**结论**: 效价随时间稳步增长，呈对数增长曲线（前 60 天增长最快，后趋于稳定）。这符合社交网络中关系建立→情感传染→稳态的心理学预期。

### 3.3 跨组别对比

| 组别 | meanValence | 说明 |
|------|-------------|------|
| 学生 | +0.02618 | 60% 的 agent |
| 教职工 | +0.02532 | 25% 的 agent |
| 周边居民 | +0.02634 | 15% 的 agent |

组间差异极小（<4%），说明均匀人格分布下社交角色本身不造成显著效价差异。

### 3.4 效价分布

5,000 agents 最终快照的效价分布：

```
min:   -0.0368
p10:   -0.0001
p25:    0.0000
median: 0.0007
p75:    0.0072
p90:    0.1034
max:    0.2980
mean:   0.0260
std:    0.0602
```

**特征**: 分布右偏，大多数 agent 效价接近零，少数 agent 有显著正效价（被社交传染影响的"社交活跃者"）。

## 4. 极端人格实验

### 4.1 效价对比（10 seeds 平均）

| 人格组 | meanValence | 标准差 |
|--------|-------------|--------|
| **高神经质** (N>0.8) | **+0.0196** | ±0.0001 |
| 低神经质 (N<0.25) | **+0.0285** | ±0.0004 |
| 高外向 (E>0.8) | +0.0243 | ±0.0003 |
| 低外向 (E<0.25) +0.0244 | ±0.0006 |

### 4.2 效应量

```
高N vs 低N 差异: +0.0089 (Cohen's d = 30.63)
```

**神经质是效价的最强预测因子**。高神经质个体效价比低神经质低 31.2%，效应量极大（d > 0.8 即为大效应，此处 d = 30.63 表明差异极其显著且一致）。

外向性对效价的影响不显著（高E ≈ 低E），说明在当前模型中，情绪传染主要通过神经质（情绪调节能力）而非外向性（社交活跃度）驱动。

## 5. 事件注入效果

模拟中注入了两类事件：

### 5.1 天气效应

| 天气 | 主要影响 | 强度 |
|------|----------|------|
| 晴天 | joy +0.025, calm +0.018 | 正面 |
| 阴天 | boredom +0.012 | 轻微负面 |
| 雨天 | sadness +0.03, frustration +0.018 | 负面 |
| 寒冷 | nervousness +0.025 | 轻微负面 |

天气每 72 ticks（6小时）有 30% 概率切换，影响按神经质系数放大（高N 放大 1.5×）。

### 5.2 人生事件

12 种人生事件（好消息、社交冲突、失恋、升职等），每 12 ticks 检查一次，概率 0.1%-1.2%，与神经质正相关。

## 6. 数据格式说明

### 6.1 二进制文件 (.f32)

```
Header (32 bytes):
  [0:4]   uint32  num_agents
  [4:8]   uint32  num_snapshots
  [8:12]  uint32  floats_per_agent (10)
  [12:16] uint32  sample_interval_ticks
  [16:32] padding

Data (num_snapshots × num_agents × 10 × 4 bytes):
  每个 agent 每个快照 10 个 float32:
    [0] valence    (正负效价: 正面情绪均值 - 负面情绪均值)
    [1] arousal    (唤醒度: placeholder)
    [2] joy
    [3] sadness
    [4] anger
    [5] fear
    [6] nervousness
    [7] boredom
    [8] calm
    [9] frustration
```

### 6.2 辅助文件

- `agents.json`: 前 1000 个 agent 的人格信息（id, group, mbti, ocean）
- `stats.json`: 场景统计（性能、组别效价、效价时间线、人格分布）

### 6.3 Python 读取示例

```python
import struct, numpy as np

with open('emotion_data.f32', 'rb') as f:
    header = struct.unpack('<4I', f.read(16))
    n_agents, n_snaps, fpa, interval = header
    data = np.frombuffer(f.read(), dtype=np.float32)
    data = data.reshape(n_snaps, n_agents, fpa)

# 获取第 100 个快照所有 agent 的效价
valence = data[100, :, 0]  # shape: (n_agents,)
```

## 7. 已知限制

1. **年度场景降规模**: 原计划 10K agents × 365天，因 macOS Jetsam 杀进程降为 1K × 365天
2. **arousal 为 placeholder**: 当前 arousal 维度未计算，固定为 0
3. **效价范围偏小**: 大多数 agent 效价在 [-0.04, +0.30]，对于 LLM 微调可能需要标准化或放大
4. **无文本轨迹**: 当前只输出数值轨迹，不包含 agent 的语言行为描述

## 8. 后续建议

1. **LLM 微调数据转换**: 将数值轨迹转换为角色描述文本（"作为神经质得分为 0.85 的 INFP，经历了连续阴雨天气后感到焦虑..."）
2. **效价标准化**: 对训练数据做 z-score 标准化，增强 LLM 对情绪变化的感知
3. **增加文本事件**: 在事件注入时生成自然语言描述，作为训练数据的一部分
4. **扩大规模**: 在 Linux 服务器上运行更大规模场景（50K+ agents），避免 macOS 内存限制
5. **增加 arousal 计算**: 基于情绪维度的方差计算唤醒度，提供更完整的情绪状态描述
