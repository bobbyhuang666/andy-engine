# Andy Engine 洞察报告：从 Bobby 到社会模拟引擎

> 从一个 AI 陪伴产品的构想，到一个心理学驱动的社会模拟引擎，再到对其市场价值的诚实反思。
> 这份记录的是一个非技术创始人在 AI 时代的探索过程。

---

## 第一章：Bobby——最初的构想

### 起点
一个低压 AI 陪伴聊天产品。概念是：一个"存在物"，有自己的生活节奏，不以讨好用户为目标。

**Bobby 做了什么**：
- 深夜氛围主题 + 时间感知背景色
- 情绪感知回复 + 碎碎念系统
- 关系深度系统 + 好感度变化
- 记忆系统 + 送礼记忆
- DeepSeek API 流式对话
- 评论区互动 + 低语系统

**Bobby 做不到什么**：
角色在没有对话的时候是"死"的。关了 app，角色就不存在了。

### 关键发现
LLM 本身无法提供"有自己的世界"——它是一个**无状态的文本生成器**。每次调用都是独立的，没有持续的内在生活。

---

## 第二章：Andy Engine——心理学驱动的解决方案

### 核心洞察
> 如果 LLM 是"大脑"，那我们需要一个"身体"——一个独立于对话之外、持续运行的内在状态系统。

### 架构
6 个心理学子系统，基于 20+ 篇同行评审论文：

| 系统 | 理论基础 | 功能 |
|------|---------|------|
| 情绪 | Cowen & Keltner 2017 (30 维) | 情绪随时间演化 |
| 人格 | OCEAN + Personality Anchor | 100 轮后不漂移 |
| 记忆 | ACT-R (Anderson 2007) | 衰减 + 关联检索 |
| 需求 | Maslow 层级 | 饱腹/精力/社交/舒适/刺激 |
| 社交 | Dunbar + Granovetter | 关系涌现 + 情绪传染 |
| 评价 | Scherer CPM | 事件 → 情绪反应 |

### 性能
- 20 agent × 10 天 = 25.6 秒（8.89ms/tick）
- 1513 测试全通过
- Rust SoA 引擎：50K agent 24.9ms/tick

## 第三章：实验验证

### 5 组实用性实验

| 实验 | 结果 | 证明了什么 |
|------|------|-----------|
| Exp1 A/B 对比 | Andy 4.92 vs Plain 2.63 | Andy 提供 10× 更多内在信息 |
| Exp2 人格一致性 | OCEAN 方差 = 0.000 | 人格完全不漂移 |
| Exp3 状态感知 | 4/5 锚定度 | 回复反映内部状态 |
| Exp4 记忆系统 | 7 天保留率 100% | ACT-R 衰减正确工作 |
| Exp5 涌现行为 | 59 对亲密朋友从 0 涌现 | 社交网络自然生长 |

### MoodBench 评测
- Andy + DeepSeek: 62.2/100（GPT-4o 评审）
- 对比：gpt-4o = 69.09, claude-opus-4 = 65.67
- Andy 在陪伴能力维度接近顶级模型

### 人格漂移测试
- 6 轮迭代（v1-v6）
- 两个 MBTI 类型（ENFJ + INFP）
- 发现：**INFP + Andy = 最佳组合**（R1→R100 从 3.2 升到 3.6）
- 发现：**锚定语义不能简化**（v3-v5 简化后效果消失）
- 发现：**GPT-4o 评审偏差**——把"疲惫"等同于"人格偏离"

## 第四章：诚实反思

### Andy Engine 做不到的事

| 能力 | Andy Engine | Prompt + RAG |
|------|------------|-------------|
| 单轮回复质量 | ✅ | ✅ |
| 100 轮人格漂移 | ⚠️ 部分抑制 | ⚠️ 部分抑制 |
| 跨天记忆 | ✅ ACT-R | ✅ RAG |
| 多角色社交 | ✅ 独特 | ❌ |
| 情绪实时演化 | ✅ 30 维 | ⚠️ Prompt 注入 |

**核心问题**：Andy Engine 的大部分功能可以用 **Prompt + RAG** 替代。

### "多角色模拟世界"是不是真需求？

| 证据 | 支持 | 反对 |
|------|------|------|
| The Sims 200M 份 | ✅ | 那是游戏，不是 AI 陪伴 |
| Replista 多角色尝试 | | ❌ 用户不买账 |
| Character.AI 火爆 | | ❌ 单角色就够了 |
| Andy Town Demo | ⚠️ 未验证 | 用户没觉得"非玩不可" |

**结论**：尚未被验证为真需求。

### 最诚实的定位

| 定位 | 价值 |
|------|------|
| AI 陪伴增强引擎 | ❌ Prompt + RAG 就能做 |
| 多角色社会模拟引擎 | ✅ 真正的独特价值 |
| 心理学驱动的 Agent 框架 | ⚠️ 有价值但 LLM 在进化 |
| **研究工具** | ✅ 证明了概念 |

**Andy Engine 不是一个"产品"，而是一个"概念验证"——它证明了心理学模型可以驱动 Agent 行为。**

---

## 第五章：接下来

### 两个方向

**方向 A：做产品**
- 用 Prompt + RAG 实现 Andy 的核心能力
- 不需要复杂的规则系统
- 面向 AI 陪伴市场

**方向 B：做研究**
- 将心理学模型蒸馏进 LLM（微调）
- 多角色社会模拟作为研究平台
- 发表论文，建立学术影响力

### 无论哪个方向，今天的洞察都有价值

1. 人格漂移不是 LLM 的 bug，是所有模型的通病
2. Andy 的价值不在于"让回复更好"，而在于"让角色有持续的内在生活"
3. 微调方案（LoRA）可以让心理学模型内化到 LLM 中
4. 多角色社会模拟尚未被验证为真需求——需要最小可行测试
