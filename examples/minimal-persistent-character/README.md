# Minimal Persistent Character

A quickstart example for Andy Engine.

## What It Shows

1. Create a character with personality and background
2. Tick the world to advance simulation
3. View character's behavior, narrative, and memories

## How to Run

```bash
node examples/minimal-persistent-character/quickstart.js
```

## Expected Output

```
=== Andy Engine Quickstart ===

1. Ticking world...
   World ticked 5 times

2. Character behavior:
   Activity: 0.XX
   Sociality: 0.XX
   Focus: 0.XX
   Expressiveness: 0.XX
   Label: ...

3. Character narrative:
   ...

4. Character status:
   State: ...
   Emotion: ...
   Social Energy: XX%
   Health: XX%

5. Character memories:
   Total memories: X
   Most recent: ...

=== Quickstart Complete ===
```

## Key Features Demonstrated

- **Persistent world**: World continues ticking
- **Character state**: Behavior evolves over time
- **Narrative generation**: Character's inner state is expressed
- **Memory formation**: Events are remembered
