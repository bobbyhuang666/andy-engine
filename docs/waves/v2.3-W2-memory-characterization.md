## 3. characterization test 设计原则

- **锁定当前行为**：用固定输入 + 固定 seed RNG，断言确定的输出（memory ids / merge pairs / baseLevel 值 / similarity 分数）。
- **非 snapshot 全等**：不锁定全量 JSON，只锁定关键行为字段（避免脆弱测试）。
- **确定性**：所有测试用固定 simTime + 固定 RNG seed，消除非确定。
- **防回归**：未来改动若改变这些锁定值，测试 fail，提示行为变更需人审。

## 4. 测试覆盖

### PersonalMemory characterization

- **retrieve**：固定 memory 集合 + context → 断言返回 top-K 的 ids 顺序（锁定检索排序行为）。
- **consolidate**：固定 memory 集合 → 断言合并的 keep/remove pairs（锁定合并决策）。
- **_baseLevelActivation**：固定 memory（含 presentations）+ now → 断言 baseLevel 数值（锁定公式）。
- **_memorySimilarity**：固定两条 memory → 断言 similarity 分数（锁定相似度计算）。

### ProceduralMemory characterization

- **recordAction + pattern formation**：固定行为序列 → 断言形成的 pattern（锁定 procedural 学习）。
- **query**：固定 context → 断言返回的 pattern（锁定检索）。
- **_matchAndStrengthen**：固定 pattern + entry → 断言匹配 + strengthen 结果（锁定强化）。
