# Audit Documents

`docs/audit/` is for current or high-signal audit artifacts.

Historical round-by-round audit reports and bug ledgers were moved to the
maintainer's private archive package outside this repository.

## Current Audit Entry Points

- `CURRENT_BUG_LEDGER.md` — living, concise ledger for current audit -> verification -> repair cycles. Start here.
- `INDEPENDENT_AUDIT_REPORT.md` — latest broad independent audit report.
- `BUG_LEDGER_R41_R42.md` — late-stage bug ledger.
- `BUG_LEDGER_R43.md` — latest uncommitted/active bug ledger when present.
- `CONVERGENCE_REPORT_R42.md` — latest convergence report.
- `domain-purity-scan.json` — machine-readable scan artifact.

Treat all audit reports as candidate evidence. Source code, tests, `AGENTS.md`, and
fresh reproduction are authoritative.
