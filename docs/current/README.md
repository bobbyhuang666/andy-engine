# Current Documents

`docs/current/` contains public-facing contracts and engineering reference notes
that should actively guide current implementation decisions.

If a document is an internal phase report, root-cause investigation, temporary task
card, model-routing note, or superseded decision brief, it belongs outside the
public repository in the maintainer archive, not here.

## Active Contracts / Engineering References

- `AFFECT_COMPILER_CONTRACT.md`
- `ALIVENESS_METRICS_v0_1.md`
- `NEED_TARGET_CONTRACT.md`

When a document stops being active, move it to an appropriate archive subdirectory
and update this README.
