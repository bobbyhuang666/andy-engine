# Andy Character Lab

一个自由事件 demo：同一个 AI 角色会把当前事件放进过往经历里理解，而不是只按当前输入走固定分支。

## 它证明什么

Andy Engine 不只是对话包装。它为角色维护持久的心理状态——情绪、需求、记忆、关系——这些状态会因为经历而改变，并影响角色对后续事件的反应。

Demo 的核心展示：

- 用户可以任意顺序点击事件，不再按固定路线推进。
- Maya 会根据当前状态、记忆、人格和关系历史生成回应。
- 页面会同时显示一个“行为树版本”的固定回复，用来对比 Andy Engine 的心理连续性。
- 重点不是她说了什么，而是她为什么这样理解当前事件。

## 运行

```bash
cd demo/character-lab
npm install
npm start
# → http://localhost:3456
```

无需 API Key，无需外部服务。所有计算在本地完成。

## 推荐试玩方式

试两组历史，然后点击同一个事件：

```text
关心她 → 陪她完成任务 → 让她休息 → 迟到
```

再重置，试：

```text
忽略她的消息 → 批评她 → 继续要求她帮忙 → 迟到
```

观察同一个“迟到”事件如何被不同历史解释。

## 技术

- 后端：Express + Andy Engine（原地调用，不走网络）
- 前端：原生 HTML/CSS/JS，无框架依赖
- 回复：基于状态阈值的模板选择，确定性输出（同状态同回复）
- 解释层：输出状态、记忆、人格、情绪变化等因果因素
- 引擎子系统：30 维情绪向量、5 层需求系统、ACT-R 记忆模型、Scherer 认知评价、OCEAN 人格
