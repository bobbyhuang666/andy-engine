### Test 1: Triadic Closure — Deterministic Strengthening

**Seed**: `'d6-triadic-closure'`

**初始条件构造**:
```
Engine: new AndyEngine({ seed: 'd6-triadic-closure', enableFacts: true })
4 agents: a, b, c, d — 同一区域（campus 默认 '校园广场' 或 custom domain 'room1'）
创建后手动建立关系：
  graph.getOrCreateRelationship('a','b').recordInteraction('talk', 0.8, 'chat') × N 次
  → 使 a-b strength ≈ 0.6, type = 'friend'
  graph.getOrCreateRelationship('b','c').recordInteraction('talk', 0.8, 'chat') × N 次
  → 使 b-c strength ≈ 0.6, type = 'friend'
  graph.getOrCreateRelationship('a','c').recordInteraction('talk', 0.3, 'chat') × M 次
  → 使 a-c strength ≈ 0.3, type = 'acquaintance'
  // a-d: 不建关系，保持 stranger (initialStrength 0.08)

beforeAll 验证：
  a-b.strength >= 0.5 && a-b.type === 'friend'
  b-c.strength >= 0.5 && b-c.type === 'friend'
  a-c.strength > 0.15 && a-c.type === 'acquaintance'
  a-d.strength < 0.15 && a-d.type === 'stranger'
```

**Deterministic assertion**:
```
const acBefore = graph.getRelationship('a','c').strength;
const adBefore = graph.getRelationship('a','d').strength;

// 跑足够 tick 使 A 至少被 _triadicClosure 的 1/3 轮询采样到
// SocialGraph._tickCount 从 0 开始，A 在 tick 0 的 offset=0 时被采样
// 但需确认 agent 排列顺序。安全策略：跑 5 tick，确保每个 agent 至少被采样 1-2 次
for (let i = 0; i < 5; i++) engine.tick();

const acAfter = graph.getRelationship('a','c').strength;
const adAfter = graph.getRelationship('a','d').strength;

// 三元闭合增量：closureRate(0.002) * bridgeStrength(min(0.6,0.6)) * saturation(1-0.3) = 0.00084
// A 被采样时 a-c 边增强。5 tick 中 A 至少被采样 1 次
expect(acAfter).toBeGreaterThan(acBefore);  // a-c 被三元闭合增强
expect(adAfter).toBeCloseTo(adBefore, 4);   // a-d 无共同朋友，不变
```

### Test 3: Social Graph Serialization Fidelity

**Seed**: `'d6-serialization-fidelity'`

**初始条件构造**:
```
Engine: new AndyEngine({ seed: 'd6-serialization-fidelity', enableFacts: true })
4 agents: a, b, c, d — 同一区域
预种子关系结构与 Test 1 相同（a-b friend, b-c friend, a-c acquaintance, a-d stranger）

记录序列化前状态：
  initialEdges: graph.toJSON() 中所有边的 { agentA, agentB, strength, type }
  initialEdgeCount: edges.length
```

**Deterministic assertion**:
```
// 跑 200 tick
for (let i = 0; i < 200; i++) engine.tick();

// 序列化 → 反序列化
const state = engine.toWorldState();
const engine2 = new AndyEngine({ seed: 'd6-serialization-fidelity', enableFacts: true });
engine2.fromWorldState(state);

// 续跑 50 tick
for (let i = 0; i < 50; i++) engine2.tick();

// 验证关系数量一致
const restoredEdges = engine2.world.socialGraph.toJSON();
expect(restoredEdges.length).toBe(initialEdgeCount);

// 验证每条关系存在且 strength 合理（衰减+续跑误差容限 < 0.05）
for (const origEdge of initialEdges) {
  const restored = restoredEdges.find(e =>
    (e.agentA === origEdge.agentA && e.agentB === origEdge.agentB) ||
    (e.agentA === origEdge.agentB && e.agentB === origEdge.agentA)
  );
  expect(restored).toBeDefined();
  // strength 误差容限：200+50 tick 衰减，但不应该差超过 0.05
  expect(Math.abs(restored.strength - origEdge.strength)).toBeLessThan(0.05);
}
```

### Test 1: Told Knowledge 2-Hop Propagation (A→B→C)

**Seed**: `'d6-gossip-2hop'`

**初始条件构造**:
```
Engine: new AndyEngine({ seed: 'd6-gossip-2hop', enableFacts: true })
3 agents: alice, bob, carol
放置到同一区域（使 encounter 可能，但我们将手动 dispatch social events）

Step 1: 让 alice 获得 fact F (direct)
  手动 dispatch 一个事件让 alice 参与：
  engine.world.eventDispatcher.createEvent({
    type: 'work',
    scope: 'public',
    participants: ['alice'],
    observers: [],
    content: 'Alice completed a project',
    time: engine.world.clock.time,
    effects: [],
  });
  // 处理事件进入 canon pipeline
  // alice 获得 fact F, evidence = { source: 'direct' }

Step 2: alice-bob social event → B learns F via told
  engine.world.eventDispatcher.createEvent({
    type: 'social',
    scope: 'public',
    participants: ['alice', 'bob'],
    observers: [],
    content: 'Alice and Bob chatted',
    time: engine.world.clock.time,
    effects: [
      { target: 'alice', type: 'relationship', delta: { target: 'bob', valence: 0.3 } },
      { target: 'bob', type: 'relationship', delta: { target: 'alice', valence: 0.3 } },
    ],
  });
  // CanonEventPipeline._propagateGossip → bob learns F (told, propagatedFrom: alice)

Step 3: bob-carol social event → C learns F via told
  engine.world.eventDispatcher.createEvent({
    type: 'social',
    scope: 'public',
    participants: ['bob', 'carol'],
    observers: [],
    content: 'Bob and Carol chatted',
    time: engine.world.clock.time,
    effects: [
      { target: 'bob', type: 'relationship', delta: { target: 'carol', valence: 0.3 } },
      { target: 'carol', type: 'relationship', delta: { target: 'bob', valence: 0.3 } },
    ],
  });
  // CanonEventPipeline._propagateGossip → carol learns F (told, propagatedFrom: bob)

注意：每个 step 后需要 tick 使 canon pipeline 处理事件。
```

**Deterministic assertion**:
```
const ks = engine.world.knowledgeStore;
const fs = engine.world.factStore;

// 找到 alice 参与的那个 fact
const aliceFacts = ks.getKnownFacts('alice');
expect(aliceFacts.length).toBeGreaterThan(0);
const factF = aliceFacts.find(f => f.description?.includes('project') || f.participants?.includes('alice'));
expect(factF).toBeDefined();

// alice: direct evidence
const aliceEvidence = ks.getEvidence('alice', factF.id);
expect(aliceEvidence.source).toBe('direct');

// bob: told, propagatedFrom alice
const bobEvidence = ks.getEvidence('bob', factF.id);
expect(bobEvidence).toBeDefined();
expect(bobEvidence.source).toBe('told');
expect(bobEvidence.propagatedFrom).toBe('alice');

// carol: told, propagatedFrom bob (2-hop)
const carolEvidence = ks.getEvidence('carol', factF.id);
expect(carolEvidence).toBeDefined();
expect(carolEvidence.source).toBe('told');
expect(carolEvidence.propagatedFrom).toBe('bob');
```

```
const checker = new FactConsistencyChecker();

// 构造 grounding package：carol 的 allowedFacts 中包含 told evidence 的 fact
```

## W3: Emotion Contagion Cluster E2E

**文件**: `tests/e2e/emotion-contagion-cluster.test.js`（新建）

**依赖**: 无（独立于 W1/W2）

### Test 1: Emotion Convergence via Social Contagion

**Seed**: `'d6-contagion-convergence'`

**初始条件构造**:
```
Engine: new AndyEngine({ seed: 'd6-contagion-convergence' })
3 agents: a, b, c — 全部放在同一区域

手动设置极端初始情绪：
  agentA.emotion.current.joy = 0.9;
  agentA.emotion.current.sadness = 0.05;
  agentA.emotion.mood.joy = 0.9;
  agentA.emotion.mood.sadness = 0.05;

  agentB.emotion.current.joy = 0.1;
  agentB.emotion.current.sadness = 0.8;
  agentB.emotion.mood.joy = 0.1;
  agentB.emotion.mood.sadness = 0.8;

  agentC.emotion.current.joy = 0.15;
  agentC.emotion.current.sadness = 0.75;
  agentC.emotion.mood.joy = 0.15;
  agentC.emotion.mood.sadness = 0.75;

建立关系（使传染权重不为默认 0.1）：
  graph.getOrCreateRelationship('a','b').recordInteraction('talk', 0.5, 'chat') × 5
  graph.getOrCreateRelationship('a','c').recordInteraction('talk', 0.5, 'chat') × 5
  graph.getOrCreateRelationship('b','c').recordInteraction('talk', 0.5, 'chat') × 5

计算初始方差：
  initialJoyVariance = variance([0.9, 0.1, 0.15])
  initialSadnessVariance = variance([0.05, 0.8, 0.75])
```

**Deterministic assertion**:
```
// 跑 100 tick
for (let i = 0; i < 100; i++) engine.tick();

// 计算 100 tick 后方差
const joyValues = [agentA.emotion.current.joy, agentB.emotion.current.joy, agentC.emotion.current.joy];
const sadnessValues = [agentA.emotion.current.sadness, agentB.emotion.current.sadness, agentC.emotion.current.sadness];

const joyVariance = variance(joyValues);
const sadnessVariance = variance(sadnessValues);

// N5: 方差下降 ≤ 初始方差的 50%（起步阈值）
// 如实测稳定，可收紧到 ≤30%
expect(joyVariance).toBeLessThanOrEqual(initialJoyVariance * 0.5);
expect(sadnessVariance).toBeLessThanOrEqual(initialSadnessVariance * 0.5);

// 辅助断言：joy 方差确实下降了（传染产生了趋同）
expect(joyVariance).toBeLessThan(initialJoyVariance);
expect(sadnessVariance).toBeLessThan(initialSadnessVariance);
```

**辅助函数**:
```js
function variance(arr) {
  const mean = arr.reduce((s, v) => s + v, 0) / arr.length;
  return arr.reduce((s, v) => s + (v - mean) ** 2, 0) / arr.length;
}
```
